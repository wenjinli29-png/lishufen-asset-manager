# 李淑芬的资产管理工具

面向 AI 视频创作的本地素材管理工具。把角色、服装、道具、场景、群演和 Skill 放在一起，按项目查找，预览后直接复制原文件。

**Windows 10 / 11 · 64 位 · 便携使用版 v19 · Chrome / Edge 插件 0.4.1**

本仓库公开提供软件下载、功能介绍与使用教程，允许下载使用；不提供应用源工程，也不将本软件声明为开源软件。

## 下载与开始使用

到本仓库的 **[Releases 下载页](https://github.com/wenjinli29-png/lishufen-asset-manager/releases/latest)**，下载 `李淑芬的资产管理工具_Windows使用版_v19.zip`。

1. 右键 ZIP，选择“全部解压”，放到有写入权限的固定文件夹。不要直接在压缩包内运行，也不要只取出一个 EXE。
2. 双击 `李淑芬的资产管理工具.exe`。所需运行组件已随包提供，不需要安装 Python、Node.js 或开发工具。
3. 软件会在默认浏览器打开本机页面。新建项目，或进入“共享素材 · 总库”，拖入自己的图片与声音。

首次运行是**新空库**，没有制作者的项目、素材数据库或百度授权。GitHub 自动显示的 `Source code (zip)` 只是这个介绍与教程仓库的归档，不是软件安装包；请下载 Releases 中单独提供的 Windows 使用版附件。

关闭网页后，后台服务仍会运行。等同步、上传、备份等任务结束，再双击 `关闭后台服务.exe`。若已有另一份软件占用默认端口，请先从那份软件目录关闭后台，再启动新版本。

## 主要功能

| 功能 | 可以做什么 |
| --- | --- |
| 项目与共享总库 | 总库保存所有素材，项目引用同一份素材；跨项目复用，不重复复制文件。 |
| 角色卡 | 独立面部封面、声音参考、服装造型和道具；一套服装一张参考图，卡片预览与拖拽排序。 |
| 场景、道具与群演 | 单图卡片、分类文件夹、搜索、预览与复制；群演支持多选复制。 |
| 快速取用 | 复制单个原文件、角色全套或本套服装道具；保留原格式与文件内容。 |
| Skill 管理 | 保存正文、概述、说明、示例封面和完整制作包；保留历史版本、比较正文、切换使用版本。 |
| 浏览器插件 | 在生成网页旁查找、预览、试听并尝试放入素材；浮钮与窗口可以拖动。 |
| 存储与备份 | 选择资产及备份目录，复制校验后切换；支持本地完整备份、百度网盘上传与下载。 |
| 回收站 | 删除前提示受影响项目，删除资料暂存三天，可在期限内恢复。 |

### 项目引用与复制范围

同一素材加入多个项目后，名称、图片等修改会在相关项目同步显示。从项目移除只是取消引用；从总库删除素材会影响引用它的项目，删除前会提示。旧版已有的独立副本保留，不会按同名自动合并。

“复制全套”包含角色各套**当前服装参考图与对应道具**；“复制本套”只取当前造型的服装和道具。两者均不包含独立面部图、声音或旧版本。声音可以单独试听、复制。群演多选复制的是多个原文件，当前不自动拼图。

### Chrome / Edge 插件

先启动主软件，再在 Chrome 的 `chrome://extensions/` 或 Edge 的 `edge://extensions/` 开启开发者模式，选择“加载已解压的扩展程序”，选便携包中直接包含 `manifest.json` 的 `浏览器插件` 文件夹。安装后刷新创作网页；完整安装说明随包提供。

插件面向即梦、LibTV、Seko、小云雀的公开入口，最低要求 Chrome 120 或相应 Chromium 版本的 Edge。它专注查找和取用；上传入库、改名、删除仍在主软件完成。

默认尝试把原文件放到当前可见页面中央，也提供选择上传框的备用方式。是否能接收取决于网站当次上传控件；请检查网站自己的预览。插件不会点击生成，不能把“已交给页面”视为上传完成。目前没有承诺四个网站登录后所有工作区均已适配。

### 本地资料与百度网盘

资料默认保存在程序旁的 `data` 文件夹，可通过“存储与备份”迁移到其他位置。文件夹切换会先复制、校验，成功后才切换；原目录保留。

百度网盘由每位使用者在百度官方页面授权自己的账号。自动同步需要主动开启：打开时检查一次，软件内修改停止约 8 秒后合并同步；空闲时不反复查询。当前云端传输单位是**完整资料库**，不是单张图片或单个项目，远端新版需用户选择下载打开。

分享给别人请发送原始发布 ZIP。已经运行过的目录可能包含自己的资料和配置，不适合整体重新压缩分享。升级前先备份并关闭后台，保留自己的资料与设置，按新版说明操作。
